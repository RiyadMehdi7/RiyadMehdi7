# Riyad Mehdiyev

Data scientist in Stockholm, currently at Kapital Bank.

I work on systems that make decisions with incomplete information: predicting what may happen, estimating which intervention could change it, and building software that lets people inspect the evidence.

My current interests are causal inference, temporal retrieval, small-model reasoning, and multi-agent development.

## Selected work

**[Cognitive LLM](https://github.com/RiyadMehdi7/cognitive-llm)**  
A controlled ablation study of six neuroscience-inspired modules added to a frozen small language model. The repository includes the training code, evaluation harness, paper, and frozen results.

**[CRVerify-P](https://github.com/RiyadMehdi7/CRVerify-P)**  
An adaptive algorithm for choosing which reasoning paths to verify when verification has a cost. It combines confidence bounds, partial-path coverage, and a stopping rule for top-*m* selection.

**[TemporalRAG-Lite](https://github.com/RiyadMehdi7/TemporalRAG-Lite)**  
A retrieval and evaluation toolkit for questions whose answer depends on a point in time. It includes time-sliced corpora, temporal-leakage metrics, recency guards, and calibrated abstention.

**[AgentSync MCP](https://github.com/RiyadMehdi7/agentsync)**  
An MCP server for coordinating coding agents in the same repository through file locks, active-work tracking, conflict detection, and merge assistance.

**[CHRONOS](https://github.com/RiyadMehdi7/CHRONOS)**  
A research framework combining survival analysis, heterogeneous treatment effects, and budget-constrained policy learning for employee retention.
